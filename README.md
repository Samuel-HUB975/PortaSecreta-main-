- [cria um personagem que se move com (WDSA)]

- **Cenas:** [a sena é um personagem em uma floresta atras das frutas]

- **Scripts:** [PlayerMovement - movimenta o jogador, GerenciadorDeJogo - contabiliza os pontos que o jogador coletar, Coletavel - serve para que o jogador consiga coletar as frutas,   ]
